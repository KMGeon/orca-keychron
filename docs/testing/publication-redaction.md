# 공개 검증 자료의 비식별화 기록

**2026-09-06 · 공개 전 자료 점검에서 발견한 실행환경 정보와 개인 경로를 제거했다.**
이 작업은 과거 검증 결과를 공개 가능한 형태로 정리한 것이며, 테스트를 새로 실행했다는 뜻이 아니다.

| 변경 | 처리 |
|---|---|
| 실패 로그에 포함된 실행환경 | 환경 변수 사전 두 곳을 통째로 `<redacted ambient environment>`로 치환했다. 일부 값만 가리는 방식은 사용하지 않는다. |
| 개인 절대 경로 | 저장소 경로는 `<workspace>`, 사용자 홈 경로는 `<home>`으로 치환했다. |
| 원본과 공개본 | 원본은 저장소 밖의 비공개 로컬 경로에 보존하고, 공개본 21개 파일의 원본·공개 SHA-256을 별도로 기록했다. |
| 검증 결과 | 테스트 결과·실패 원인·사례 식별자는 유지한다. JSON과 JSONL은 비식별화 후에도 파싱됨을 확인했다. |
| 새 로컬 실행 상태 | `.gjc/_session-*/`와 `.gjc/state/`는 Git에서 제외한다. 프로젝트 hook과 agent 정의까지 일괄 제외하지는 않는다. |

[기계 판독 매핑](publication-redaction.json)의 `originalSha256`은 당시 원본,
`publishedSha256`은 지금 공개한 파일을 식별한다. 이전 감사 기록의 해시는 당시 실행·검토 시점을
설명하므로 새 결과처럼 덮어쓰지 않는다. 공개본의 바이트 일치는 이 매핑으로 확인한다.

제품 코드와 동작 테스트는 이 비식별화 작업에서 변경하지 않았다. 검증 자료를 다시 수집할 때에는
질문·답변 내용, credential뿐 아니라 오류 출력의 전체 환경 변수와 사내 주소까지 확인한다.
